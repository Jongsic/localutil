GitHub and servers often show only a SHA256:… fingerprint. Paste it here to check whether it belongs to the key above.
A fingerprint is a one-way hash of the key — it cannot be turned back into the key. But every representation of the same key hashes to the same fingerprint, which is exactly what the comparison checks.
